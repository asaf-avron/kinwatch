# Feature requests

| Request | Why it matters | Priority |
| --- | --- | --- |
| Partner lock / deadbolt actuation with explicit household consent | Caretaking stories want “lock it” after a false open. Inventing `set_lock_state` fails certification and judging. A real, consented write would change the product. | Critical |
| Event History for contact sensors | Sensors have no DVR. Household memory is a workaround, not a substitute, for “was the door open at 2:11 last Tuesday?” | Critical |
| Longer-lived Playground tokens (24h) + refresh | Filming and judge-run need more than a short Bearer. | Important |
| Alexa+ confirmation of MCP 2026-07-28 (or pin 2025-11-25 in the toolkit) | Spec drift is a Stage 1 foot-gun. | Important |
| Official canned WHEP session in Playground | Lets a browser complete live view without hardware. | Important |
| AgentCore Runtime sample with extra FastAPI routes | Webhooks + companion + `/mcp` in one process is the real app. | Nice-to-have |
| MCP Apps preview in Alexa+ simulator | Creative bar currently requires a custom host to be visible. | Nice-to-have |
| API-side HMAC rotate and webhook URL update | Portal-only secrets slow staging. | Nice-to-have |
