# Contributing

This is the public Kinwatch repo for the Amazon Developer Hackathon (submit by 23 Oct 2026).

- Issues and PRs welcome on product, a11y, Ring fixtures, and docs.
- Do not commit secrets, Ring tokens, HMAC keys, or Paperclip board tokens.
- Do not add lock-actuation APIs.
- Feature branches + PRs. Do not push secrets to `main`.

Run tests: `pip install -e ".[dev]" && pytest`.
